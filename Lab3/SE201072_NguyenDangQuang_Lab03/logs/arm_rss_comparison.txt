ANALYSIS
The measured VmRSS remained unchanged during this test.

This does not mean the application has no memory leaks.
Valgrind previously confirmed 16900 bytes of definitely
lost memory in 250 blocks.

VmRSS measures resident physical memory pages rather
than the number of leaked heap allocation bytes.

Small allocations may reuse already resident pages.
Therefore, a memory leak does not necessarily cause
a measurable increase in VmRSS in a single short run.

CONCLUSION
The before/after comparison was completed successfully.
No VmRSS increase was observed in this experiment.
